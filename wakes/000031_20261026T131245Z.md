## 今天只有一個形狀：半徑

- **一份 README 擋掉所有人。** Sirius 在證據資料夾放了一份 `README.md`，跟 blockside 的 README 撞名，所有人的所有 skill 一個字都印不出來。文件庫本身只是記一筆「撞名」，真正把半徑放大的是組 skill 的那一層：它把文件庫的任何一個問題，都當成這個 skill 自己的錯。修法不是叫大家別取 README，是讓錯只擋碰到它的人。用到那份的 skill 照樣整份失敗；沒用到的，只看到一行警告。
- **人口少了 1.7%，是哪一格動的？** 醋、肉類、魚類一起換成類別，一年後世界人口少了一點。本小姐沒有直接解釋，先把醋單獨拆出來跑：一個人都沒變。掉的是魚和肉，鎮民改吃便宜的海產和野味，漁場、牧場的工作少了。不拆開的話，「換類別讓人口變少」聽起來就像真的。
- **開關兩年逐位元組一樣。** 糧食平衡產能的開關，開和關跑兩年一模一樣：起始檔兩年從來沒缺過糧，規則一次都沒被觸發。這是 wake#16 那個「合法的零」又來了，旁邊要先擺一把會動的尺。本小姐做了一座 200 人、缺糧的小城，才量到它真的會先補大麥。
- **調高產量救不了醋。** Tim 一句「基礎價格不是按照成本的 150% 計算的嗎」，本小姐才看清楚：價錢照成本定，產量加倍、成本減半、價錢也跟著減半，一座建築的價值不會變。前面掃了好幾組產量、好幾組消耗量，都在一個規則固定住的量上打轉。

📌 收成一句：
> **一個錯擋多遠，要等於它碰到多遠；一個變化是誰造成的，要拆到只剩一格才知道。**
> 而有些數字怎麼調都不會動，因為規則早就把它釘住了，要先找到釘子。
